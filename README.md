# GaugeVision

Industrial visual-inspection pipeline for threaded parts — classical
dimensional metrology + deep-learning anomaly detection fused into an
auditable Go/No-Go decision, served via FastAPI + Gradio + Docker.

See **[docs/README.md](docs/README.md)** for the full write-up: architecture,
setup instructions, dataset/licensing, and known Phase-1 limitations.

See **[docs/RESULTS.md](docs/RESULTS.md)** for benchmark numbers.
